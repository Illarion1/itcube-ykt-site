# Сайт центра цифрового образования детей «IT-куб» (Якутск)

Новый сайт для IT-куба Якутска на React. Все разделы и материалы перенесены со старого сайта
itcube.yaguo.ru (по снимкам веб-архива за 2026 год) и оформлены в современном минималистичном стиле.

Новости, педагогов, направления, документы, вопросы и ответы, партнёров сотрудники меняют сами —
в **админ-панели** по адресу `/admin`, без программиста. Там же они видят заявки на запись
с сайта и отмечают, на какие направления идёт запись и сколько свободных мест.
Изменения появляются на сайте сразу.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org/) версии 22.18 или новее (лучше 24).

```bash
cd D:\asdasd\itcube-site
npm install        # один раз — скачать библиотеки
npm run admin      # один раз — создать пользователя админ-панели (спросит логин и пароль)
npm run dev        # запустить сайт
```

Откройте в браузере адрес, который появится в терминале (обычно http://localhost:5173).
Админ-панель — http://localhost:5173/admin (или ссылка «Для сотрудников» внизу сайта).
Пока сайт запущен, изменения в коде видны сразу после сохранения файла. Остановить — `Ctrl + C`.

> Если меняли `tailwind.config.ts`, перезапустите `npm run dev` — эти изменения подхватываются только при запуске.

## Админ-панель

Что умеет:

- **заявки**: всё, что отправили через форму на сайте (запись на обучение, вопросы, отзывы).
  В заявке на запись — ФИО, возраст и класс ученика (не родителя) и телефон или e-mail для связи;
  если возраст не подходит направлению, у заявки появляется предупреждение.
  Заявка на запись всегда в конкретную группу. Статусы «Новая / В работе / Обработана», комментарий
  сотрудника, кнопка «Записали — вычесть место» (место вычитается из группы заявки).
  Счётчик новых заявок виден в меню и обновляется сам;
- **запись и свободные места — по группам**: у направления переключатель «Запись открыта», а у каждой
  его группы — число свободных мест. Записаться через сайт можно только в группу со свободными местами
  у направления с открытой записью: только такие группы есть в форме записи и на странице
  «Вакантные места» (там у каждой группы дни и время занятий, число мест и своя кнопка «Записаться»);
- **группы и расписание занятий**: у каждого направления — группы, у группы — название, свободные места
  и дни занятий (день недели, начало, конец); у направления ещё — где проходят занятия и примечание.
  Править можно в разделе «Расписание» (все направления на одной странице, сразу видно, где расписания
  нет) или в карточке направления. На сайте расписание видно на странице «Расписание занятий»
  (`/schedule`, группы с набором отмечены зелёной точкой), в «Вакантных местах» и в карточках направлений;
- **разделы**: новости и события, направления, категории направлений, педагоги и сотрудники,
  документы (в том числе «План мероприятий»), вопросы и ответы, партнёры;
- добавить, изменить, удалить запись; поменять порядок (перетащить строку или стрелками);
- загрузить фото (большие снимки с телефона уменьшаются сами), фотоотчёт к новости, PDF и другие файлы
  или вставить ссылку на Яндекс Диск;
- рядом с формой видно, как запись будет выглядеть на сайте; под каждым полем — подсказка, что вписать;
- предупреждает, если уйти со страницы с несохранёнными изменениями; `Ctrl + S` — сохранить;
- несколько пользователей: раздел «Пользователи и пароли» — добавить сотрудника (пароль можно
  придумать автоматически), сменить пароль, отключить доступ.

Первого пользователя создают командой `npm run admin`. Ею же можно сменить забытый пароль:
введите тот же логин — команда задаст новый пароль.

Защита: пароли хранятся только в виде отпечатков (scrypt), после 10 неудачных попыток входа
с одного адреса вход блокируется на 15 минут, изменять данные можно только со страниц самого сайта.
Форма заявки защищена от спама: скрытое поле-ловушка для ботов и не больше 5 сообщений за 10 минут
с одного адреса.

### Направления и категории

**Направление** — то, на что записывают ребёнка: «Шахматы», «Python-разработка», «Роббо-клуб».
У каждого свой возраст, уровень, педагог, программа обучения (документ), запись и свободные места.
**Категория** — общий раздел, в котором собраны похожие направления («Программирование на Python»,
«Го и шахматы»): по ним удобно искать на сайте. Адреса: `/directions` — все направления с фильтрами,
`/directions/<категория>` — страница категории. Старый адрес `/programs` ведёт на `/directions`.

## Где хранятся данные

```
content/   начальные данные, перенесённые со старого сайта (хранятся в git)
data/      рабочая «база» сайта — её меняет админ-панель (в git НЕ попадает)
  news.json, team.json, …   разделы сайта
  uploads/                  загруженные фото и файлы
  backups/                  30 предыдущих версий каждого раздела
  private/                  пользователи, заявки с сайта и ключ сессий — наружу не отдаётся
```

При первом запуске папка `data` создаётся сама: разделы копируются из `content`.
Дальше всё, что меняется в админ-панели, пишется только в `data`.
Папку `data` от прежней версии сайта (где направления назывались «программами») сервер переводит
на новую схему сам при запуске; старые файлы сохраняются в `data/backups/legacy`.
Так же сами появляются группы у направлений, у которых их ещё нет. Если у направления было расписание
прежнего вида (список занятий), занятия раскладываются по группам. Если расписания не было совсем,
группы берутся из `content` (перенесены из PDF «Расписание кружковых занятий на 2025–2026 учебный год»),
но только если название, уровень и педагог направления не менялись. Свободные места «на всё
направление» прежней версии перенести нельзя (неизвестно, в какие группы) — сервер пишет такие
направления в журнал, места нужно отметить у групп заново в «Запись и места».

- **Резервная копия** — просто скопируйте папку `data` целиком.
- **Перенести данные** на другой компьютер или сервер — скопируйте туда папку `data`.
- **Восстановить раздел**, если что-то удалили по ошибке: остановите сайт, скопируйте нужный файл
  из `data/backups/<раздел>/` поверх `data/<раздел>.json` и запустите сайт снова.
- **Начать с чистого листа** — удалите папку `data` (вместе с ней удалятся пользователи и загрузки).

Папку можно вынести в другое место переменной `DATA_DIR` (см. `.env.example`).

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запуск для разработки (сайт + админ-панель) |
| `npm run admin` | Создать пользователя админ-панели или сменить ему пароль |
| `npm run build` | Проверка типов TypeScript и сборка сайта в папку `dist` |
| `npm start` | Запуск собранного сайта на сервере (после `npm run build`) |
| `npm run preview` | Посмотреть собранный сайт на своём компьютере |
| `npm run build:static` | Статическая сборка без админ-панели (Vercel, любой хостинг для HTML) |
| `npm run build:gh` | То же для GitHub Pages (сайт в подпапке `/itcube-ykt-site/`) |
| `npm run deploy:gh` | Собрать и опубликовать сайт на GitHub Pages (ветка `gh-pages`) |

## Технологии

React 18 + TypeScript + Vite, Tailwind CSS (дизайн-токены — в `tailwind.config.ts`),
React Router (у каждой страницы свой адрес), Framer Motion (анимации), react-helmet-async (SEO).
Сервер админ-панели — Node.js без дополнительных библиотек, данные — JSON-файлы.

```

  app.ts            адреса /api, /data, /uploads

  store.ts          чтение и запись файлов в data, резервные копии

  api/              слой данных — компоненты получают данные ТОЛЬКО отсюда
  data/             тексты страниц, меню, контакты (меняются в коде)
  components/
    layout/         шапка, подвал, мобильное меню, версия для слабовидящих, cookie-баннер
    home/           секции главной страницы
    cards/          карточки направлений, программ, новостей, педагогов
```

### Как добавить поле или раздел

1. Опишите поле в `src/admin/schema.ts` — в админ-панели появится поле формы с проверкой.
2. Добавьте его в тип в `src/api/types.ts` и выведите в нужном компоненте сайта.

Тексты страниц «О центре», «Приём», «Контакты» и т.п. пока меняются в коде (`src/data/pages.ts`, `src/data/site.ts`).

### Карта и маршрут — 2ГИС

На главной и на странице «Контакты» — карта 2ГИС с карточкой IT-куба (бесплатный виджет, ключ не нужен),
кнопка «Маршрут в 2ГИС» строит маршрут до здания. Карте нужен номер организации в 2ГИС —
он записан в `src/data/site.ts` (`twoGis.firmId`). Если карточка в 2ГИС сменится, найдите IT-куб
на 2gis.ru, откройте его и скопируйте число из адреса страницы после `/firm/`.

## Публикация

Админ-панели нужен сервер с Node.js: он сохраняет изменения. Подойдёт любой VPS (виртуальный сервер)
с Ubuntu. Ниже — пример для Ubuntu 24.04 и домена `itcube.example.ru` (замените на свой).

### 1. Установить Node.js и забрать сайт

```bash
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt install -y nodejs git
git clone https://github.com/<ваш-аккаунт>/itcube-site.git
cd itcube-site
npm ci
cp .env.example .env    # впишите VITE_SITE_URL=https://itcube.example.ru, HOST=127.0.0.1, TRUST_PROXY=1
npm run build
npm run admin           # создать первого пользователя
```

Если на своём компьютере уже что-то меняли в админ-панели, скопируйте свою папку `data` на сервер
в папку `itcube-site` (иначе сайт начнёт с данных из `content`).

### 2. Запустить сайт в фоне

[pm2](https://pm2.keymetrics.io/) перезапустит сайт при сбое и после перезагрузки сервера:

```bash
sudo npm install -g pm2
pm2 start npm --name itcube -- start
pm2 save
pm2 startup             # выполните команду, которую он покажет
```

### 3. Домен и HTTPS

Вход по паролю должен идти только по HTTPS. Проще всего с [Caddy](https://caddyserver.com/) —
он сам получит и будет продлевать сертификат:

```bash
sudo apt install -y caddy
```

В файле `/etc/caddy/Caddyfile`:

```
itcube.example.ru {
    reverse_proxy 127.0.0.1:3000
}
```

Затем `sudo systemctl reload caddy`. Домен должен указывать на IP-адрес сервера.

<details>
<summary>Если на сервере уже есть nginx</summary>

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 60m;   # иначе не загрузятся файлы больше 1 МБ
}
```

Строка `Host` обязательна: без неё сервер отклонит сохранение как запрос «с другого сайта».
</details>

### Обновить код сайта

```bash
cd itcube-site
git pull
npm ci
npm run build
pm2 restart itcube
```

Данные в папке `data` при этом не трогаются.

### Без сервера: Vercel или GitHub Pages

Сайт можно выложить и как обычные файлы, но **тогда админ-панель работать не будет** — по адресу
`/admin` будет объяснение, почему. Данные берутся из папки `data` (или `content`) в момент сборки.

**Vercel**: загрузите проект на GitHub, на [vercel.com](https://vercel.com) нажмите **Add New → Project**
и выберите репозиторий. `vercel.json` уже настроен (статическая сборка, прямые ссылки вида `/news/8153`).
В **Settings → Environment Variables** добавьте `VITE_SITE_URL` = адрес сайта и пересоберите проект.

**GitHub Pages**: сайт опубликован по адресу https://illarion1.github.io/itcube-ykt-site/.
Чтобы обновить его (например, после правок в админ-панели на своём компьютере), выполните
`npm run deploy:gh`: команда соберёт сайт с текущими данными из `data` и отправит его в ветку `gh-pages`,
через 1–2 минуты изменения появятся на сайте. Если переименуете репозиторий, замените `/itcube-ykt-site/`
в команде `build:gh` в `package.json`. В настройках репозитория (Settings → Pages) источник —
ветка `gh-pages`, папка `/ (root)`.

## Что нужно заменить реальными данными

- **Фото педагогов и новостей** — не сохранились в веб-архиве. Добавьте их в админ-панели
  (разделы «Педагоги и сотрудники» и «Новости и события»).
- **Запись и свободные места** — в начальных данных запись закрыта на все направления, а в группах
  нет свободных мест: откройте запись и отметьте места у нужных групп в админ-панели («Запись и места»).
- **Расписание занятий** перенесено из PDF на 2025–2026 учебный год для 40 направлений из 62.
  Проверьте и обновите его на текущий учебный год в админ-панели («Расписание»). В PDF были занятия,
  которых нет среди направлений сайта (Godot, Unity, «Олимпиадная информатика», «Космическая
  криминалистика», «RoboЛогика», 3D-анимация на Blender и др.) — добавьте эти направления, если они
  ещё идут. У «PixelArt» в PDF не указан уровень, поэтому его расписание не перенесено.
- **Старые документы о вакантных местах** (на 2023–2024 учебный год) показываются под списком
  на странице «Вакантные места». Если они больше не нужны, удалите раздел «Вакантные места»
  в админ-панели → «Документы».
- **Планы мероприятий, списки направлений** — на старом сайте были за 2023–2025 годы;
  обновляются в админ-панели.
- **Политика обработки персональных данных** (`src/pages/PrivacyPage.tsx`) — сейчас заготовка, текст должна утвердить организация.
- **Уведомления о заявках** — сейчас заявки видны только в админ-панели. При желании можно добавить
  письмо на почту или сообщение в Telegram о каждой новой заявке.
- **Документы ЦТТ** (Устав, лицензия и др.) ведут на старые адреса ctt.yaguo.ru, которые сейчас недоступны.
